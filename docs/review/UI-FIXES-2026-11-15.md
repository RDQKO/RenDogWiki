# 렌독위키 문서·모달 오류 수정 및 에디터 기능 추가

기준: `audit/full-review-2026-11-15`의 `fab6569` 위에 구현한 별도 브랜치.
`main` 병합, 운영 배포, 운영 DB 변경은 하지 않았다. 이 변경에는 DB 마이그레이션이 필요하지 않다.

## 요청별 변경

| 요청 | 원인 또는 구현 방식 | 결과 |
| --- | --- | --- |
| 문서 재선택 시 목차 위치와 최상단을 왕복 | 목차와 문서의 두 스크롤 처리 코드가 이전 해시를 반복 적용 | 문서 이동 시 오래된 해시를 제거하고 최상단 표시. 목차 클릭은 문서의 공통 이동 처리로 전달. 같은 URL을 메타데이터 갱신으로 다시 불러오지 않음 |

## 펼침·접힘 사용법

1. 에디터에서 본문을 드래그로 선택한다.
2. 도구 모음의 **▸ 접기**를 누르고 제목, 기본 펼침/접힘을 설정한다.
3. 텍스트 선택 후 우클릭 메뉴의 **선택 영역을 펼침·접힘으로 묶기**로도 만들 수 있다. 이 경우 기본 펼침으로 생성한다.
4. 영역 제목의 우클릭이나 **⋯**에서 제목·기본 상태 변경, 편집 중 펼침/접힘, 아래 빈 문단, 내용 유지하며 영역 해제, 영역과 내용 삭제를 선택한다.
5. 문서 저장 후 독자는 제목을 눌러 펼치거나 접는다. 기본 상태는 문서 데이터에 저장되고, 독자의 임시 전환은 저장하지 않는다.

부분 텍스트 선택은 선택한 텍스트만 분리해 묶는다. 표·카드 같은 복합 블록은 구조를 유지해 묶는다. 중첩 영역, 실행 취소·다시 실행을 지원한다. 닫힌 영역 안의 제목도 목차·검색 대상이며, 목차로 이동할 때 부모 영역을 자동으로 펼친다.

문서 새 진입·재선택·새로고침은 최상단을 표시한다. 사용자가 직접 누른 목차, 본문 제목 링크, 검색 결과의 제목 이동은 별도의 명시적 이동 요청으로 처리한다. 브라우저 뒤로/앞으로 이동의 스크롤 복원은 유지한다.

## 추가 모달 점검

- `Modal`과 기존 `RdModal`을 같은 포털 구현으로 통합.
- 열려 있는 최상위 모달에만 Esc·Tab 처리를 적용하고 닫은 뒤 이전 포커스 복원.
- SSR에서 `document` 접근 방지, 화면 높이 제한, 모달 본문 스크롤 허용.
- 업로드 진행 중 추가 파일 드롭·선택 차단으로 처리 중인 목록 변경 방지.
- 무기 설정 창에 화면 높이 제한 추가. 중첩된 이미지 선택 모달의 키 입력을 뒤쪽 무기 모달이 가로채지 않도록 수정.
- 관리 주소 직접 접근 시 로그인 필요/권한 부족 안내와 확인 버튼을 표시하고, 확인 시 위키로 이동. 서버 API 권한 검사는 그대로 적용.
- FAQ 수정 권한은 기존 writer/admin 범위, 삭제는 admin으로 유지.
