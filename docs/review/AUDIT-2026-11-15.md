# 2026-11-15 기술 점검 브랜치

`audit/full-review-2026-11-15`는 문서 저장·권한·검색·캐시·미디어 삭제·조회 집계의 안정성 개선과 의존성 보안 업데이트를 검토하기 위한 브랜치입니다. main 병합과 운영 DB 변경은 수행하지 않았습니다. 운영 DB 진단의 자세한 수치와 미완료 범위는 사용자에게 전달하는 별도 전체 보고서에 정리했습니다.

## 주요 변경

- writer/admin·업로더 권한을 서버에서 확인하고 Ably 브라우저 토큰은 구독 전용으로 제한합니다.
- 문서 메타·본문·검색 인덱스를 트랜잭션으로 저장하며, 새 에디터는 수정 시각이 달라지면 409로 충돌을 안내합니다.
- 잘못된 본문을 빈 문서로 덮어쓰지 않고, 신규 저장 후 ID·수정 시각을 보관합니다.
- 검색/목록 기본 limit, 분류 순환, 삭제 중 부분 반영, S3 부분 실패, 예전 채팅 리액션 API를 수정했습니다.
- 문서별 캐시 무효화, NPC·마을 목록 갱신, 제한된 로컬 fallback, 검색 인덱스 배치 INSERT를 사용합니다.
- 문서·FAQ 조회 집계를 한 SQL로 처리합니다. 마지막 집계 후 10분에 한 번이며 재방문이 쿨다운을 연장하지 않습니다.
- Next.js 15.5.29에 맞춰 cookies/params를 비동기로 전환하고 이미지·메일 라이브러리와 잠금 파일을 갱신했습니다.
- 로컬 PostgreSQL 통합 테스트, 실제 Next HTTP 점검, PR 품질 검사를 추가했습니다.

SQL은 자동 실행하지 않습니다. Supabase Auth를 사용하지 않는 현재 서버 전용 DB 구조에 맞춘 안이므로 다른 Data API 소비자가 있는지 확인한 뒤 스테이징에서 검증합니다. 운영 데이터를 자동 정리하는 코드는 추가하지 않았습니다.

## 배포 전 확인

`JWT_SECRET`와 `MANAGE_DELETE_PASSWORD`를 실제 환경 값으로 설정해야 합니다. Node 22 이상과 새 잠금 파일을 사용합니다. 변경 후 브라우저의 에디터·모바일 조작, 실제 S3/SMTP/Ably 연동을 추가 검수해야 합니다. 이 브랜치에 운영 DB 진단 SQL을 포함했다고 해서 DB 접근 권한이 변경된 것은 아닙니다.
